Human verification coding

코딩 규칙

모델에게 준 지시문과 동일합니다. 비교가 성립하려면 같은 규칙을 써야 합니다.

대원칙

  • 보이는 것만 코딩합니다. 치료적 질·정확성·효과·안전성은 판단 대상이 아닙니다.
  • 입력만으로 정말 판정이 안 되면 기타 / 해당 없음을 고릅니다. 자신 있게 추측하지 않습니다.
  • 근거는 12장의 프레임과 전사뿐입니다. 영상을 따로 찾아보지 마세요.

A1 주요 기법 — 주된 실습 하나

  • 호흡 집중: 주의를 호흡이나 하나의 대상에 묶어 둠
  • 바디스캔: 신체 부위를 순서대로 훑음
  • 자애: 선의·연민의 문구를 반복(메타)
  • 열린 관찰 마음챙김: 떠오르는 무엇이든 열어 두고 알아차림
  • 심상·시각화: 장면이나 이미지를 유도
  • 요가 니드라·이완: 누워서 하는 깊은 이완, NSDR류
  • 움직임·걷기: 걷기 또는 마음챙김 움직임
  • 기타: 위 일곱에 들어맞지 않음

A2 화면 호흡 가이드

들숨·날숨을 맞추게 하는 움직이는 페이서(커졌다 작아지는 도형, 경로를 따라 가는 점)만 "있음". 정지 이미지는 페이서가 아닙니다. 호흡을 말로만 유도하는 것도 아닙니다.

A4 시각·언어 일치

페이서 속도와 말로 유도하는 호흡 속도가 맞는지. 페이서가 없거나 언어 유도가 없으면 해당 없음. 페이서가 없다고 답하면 자동으로 채워집니다.

A5 진행자 노출

사람이 화면에 나와 진행하면 "화면에 등장", 사람 없이 영상·이미지에 목소리만 얹히면 "영상만, 목소리만", 두 가지가 섞이면 "혼합".

A6 주된 배경 — 지배적인 것 하나

스튜디오·실내 / 자연 / 추상·애니메이션 / 텍스트만 / 기타.

A7 자연 이미지 존재

주된 배경이 무엇이든, 어디에든 자연 이미지가 나오면 "있음". A6과 독립적입니다. 배경이 스튜디오여도 창밖 풍경이 나오면 "있음".

A8 자세·수인 시연

앉거나 누운 명상 자세, 또는 특정 손 모양(수인)을 화면에서 보여주면 "있음". 말로만 설명하는 것은 아닙니다.

아무 곳이나 눌러 닫기

숫자키로 선택하면 다음 문항으로 자동 이동합니다. 마지막 문항을 고르면 다음 영상으로 넘어갑니다. ← → 영상 이동, Backspace 이전 문항. 진행 상황은 브라우저에 자동 저장되지만, 작업이 끝나면 반드시 내보내기를 눌러 파일을 저장하세요.

모델이 매긴 코드는 이 화면에 없습니다. 비교의 독립성을 위한 것이니 다른 곳에서도 찾아보지 마세요.
